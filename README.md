# [سهل] مواعيد السيلز

**اللينك:** https://shal-agency.github.io/sahl-meetings/

موقع بيسجّل فيه كل سيلز اجتماعاته، وبيوصله **إشعار على الموبايل أو اللابتوب** قبل كل اجتماع، حتى لو الموقع مقفول.

- **من غير تسجيل:** السيلز يفتح اللينك ويكتب اسمه أول مرة بس.
- اجتماعات كل سيلز **مربوطة بجهازه، ومحدش غيره بيشوفها**.
- الميعاد بيظهر **بتوقيت مصر والسعودية مع بعض**. السيلز يكتب الميعاد زي ما العميل قاله ويختار "توقيت السعودية".
- السيلز يختار التذكير لكل اجتماع: قبلها بيوم، أو بساعة، أو بنص ساعة، أو بـ 10 دقايق، أو في الميعاد نفسه.
- حالات الاجتماع: قادم، تم، اتأجل، اتلغى، العميل ما حضرش. وفيه تنبيه للاجتماعات اللي ميعادها عدّى وحالتها ما اتحدّثتش.

> ⚠️ اجتماعات السيلز محفوظة على المتصفح اللي سجّل منه. لو مسح بيانات المتصفح أو فتح من جهاز تاني، هيبدأ من الصفر. على الآيفون لازم يستخدم الأيقونة اللي على الشاشة الرئيسية دايماً.

## إزاي شغال
| الجزء | فين |
|---|---|
| الموقع | GitHub Pages: الريبو ده، ومن فرع `main` |
| البيانات والتذكيرات | Supabase: منظمة **Sahl**، ومشروع **sahl-meetings** (الخطة المجانية) |
| اللي بيبعت الإشعارات | Edge Function اسمها `send-reminders`، والكود في `supabase/functions/send-reminders/index.ts` |
| الجدولة | pg_cron كل دقيقة، وبتنادي الـ function بس لو فيه تذكير جه ميعاده |
| مفاتيح الإشعارات وسر الجدولة | بيتعملوا لوحدهم ومحفوظين في جدول `app_settings`، ومحدش يقدر يقراه من الموقع |

## ابعت للسيلز الخطوات دي

| الجهاز | الخطوات |
|---|---|
| **أندرويد** | افتح اللينك من Chrome ← اكتب اسمك ← "فعّل الإشعارات" ← سماح. ولو الإشعار بيتأخر: الإعدادات ← التطبيقات ← Chrome ← البطارية ← "بدون قيود". |
| **آيفون** | لازم iOS 16.4 أو أحدث. افتح اللينك من **Safari** ← زرار المشاركة ← **"إضافة إلى الشاشة الرئيسية"** ← افتح من الأيقونة ← اكتب اسمك ← "فعّل الإشعارات". واستخدم الأيقونة دي على طول. |
| **لابتوب** | Chrome أو Edge ← اكتب اسمك ← "فعّل الإشعارات". المتصفح لازم يكون شغال، حتى لو مفيش تاب للموقع مفتوح. |

## لو حاجة مش شغالة
- **الإشعار التجريبي مش بيوصل:** في Supabase افتح **Edge Functions ← send-reminders ← Settings**، واتأكد إن **Verify JWT with legacy secret** مقفول. الـ function بتتحقق بنفسها من كل طلب.
- **التجريبي بيوصل والتذكيرات لأ:** افتح **Integrations ← Cron**، والمفروض تلاقي `sahl-send-reminders` شغالة كل دقيقة. ولو عايز تشوف الأخطاء: **Edge Functions ← send-reminders ← Logs**.
- **Supabase وقف المشروع:** المشروع المجاني بيتوقف بعد أسبوع من غير ما حد يستخدمه. ترجّعه من لوحة Supabase بزرار Resume.
- **عايز تعيد إعداد قاعدة البيانات:** شغّل `supabase/setup.sql` من **SQL Editor**. الملف آمن لو اتشغّل أكتر من مرة.
